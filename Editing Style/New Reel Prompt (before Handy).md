# Prompt for a new reel

Copy this into a new chat opened on the `Editor` folder. Replace everything in angle brackets. Delete the lines you don't need.

```
Use the talking-head-reel skill.

Edit the video in Raw/<FOLDER NAME>.
Topic: <what the video is about, in one or two lines; the product, repo or link if there is one>.
CTA: <e.g. "comment LINK and I'll DM the setup guide">.
Correct wording: <optional: the key lines as they should be said, or "use my best takes">.

Style:
- Study References and Approved Videos (pull a frame every second with FFmpeg and look at them).
- <Pick one> Keep using Brand Kit/brand-kit.md.
  / I added a new reference, References/<FILE>. Build a new brand kit from it and ignore the old one.

Edit:
- Use only my best takes: every word correct and my voice confident. Not the first takes. If there is a separate voiceover file, use it and lip-sync it to the camera.
- Make all the cuts. Hook first, every sentence complete, no dead pauses.
- Zoom in and out on my camera, with punch-ins on the key words.
- Show motion graphics only for what I actually say. Use the real assets in the Assets folder. Make the hook, the product reveal, the link and the comment CTA look premium.
- Add beautiful Romanized Hinglish captions for every word, with one big hero word per line.
- Make it visually appealing and give it the best chance to go viral.

Process:
- First show me the storyboard dashboard. I want one card per beat, with the captions, each graphic and the word that triggers it, the B-roll and assets, the camera, and Approve, Reject and Feedback.
- Wait for my review, and read all my feedback, including the notes on approved beats.
- Render the final 1080x1920 video only after I say "start render". Then tell me what you checked and what you couldn't.
- Copy it to Approved Videos only after I approve it.
```

## Short version

Use this when the brand kit and approach stay the same:

```
Use the talking-head-reel skill to edit Raw/<FOLDER NAME>. Topic: <topic>. CTA: <cta>. Same brand kit, best takes only, storyboard first.
```

## Tips for the recording

- Record a few seconds of the empty frame (no one in shot) at the start or end. The speaker cutout is much cleaner with it.
- If you record a separate voiceover, record it at the same time as the camera, so it can be synced automatically.
- Put screenshots and screen recordings of everything you mention in `Raw/<FOLDER NAME>/Assets`. Graphics are built only from real material.
